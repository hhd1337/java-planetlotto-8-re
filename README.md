# woowacourse 8기 최종 코딩테스트 - 행성로또

## 기본기능구현 목록

- [x] 구입 금액을 입력받는다.
- [x] 입력한 금액에 맞는 개수의 로또를 생성한다.
    - 조건) 로또 번호는 1부터 30까지 중 중복되지 않는 숫자 5개이다.
- [x] 구매한 개수와 자동으로 생성된 로또 번호를 출력한다.
- [x] 당첨 번호를 입력받는다.
    - 예외) 숫자가 아닌 값이 포함되어 있을 경우
    - 예외) 입력된 숫자가 5개가 아닐경우
    - 예외) 1부터 30 사이가 아닌 숫자가 포함되어 있을 경우
    - 예외) 입력된 5개의 숫자 중 중복된 숫자가 있을 경우
- [x] 보너스 번호를 입력받는다.
    - 예외) 숫자가 아닐경우
    - 예외) 숫자가 1부터 30 사이가 아닐 경우
- [x] 로또의 당첨 결과를 계산한다.
- [x] 당첨 통계를 포맷에 맞게 출력한다.

## 도전과제

- [x] 리팩토링 : 필요한 객체들을 생성해서 주입해주는 Config 객체추가
  스프링 컨테이너 처럼 애플리케이션 실행 전에 먼저 필요한 객체들을 생성해두고,
  그 과정에서 각 객체의 의존성까지 연결을 해줍니다.
  이렇게 생성된 객체들을 사용하는 방식으로 코드 품질을 높이는 것을 시도해보았습니다.
